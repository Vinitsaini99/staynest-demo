# StayNest — Premium Urban Living

Custom PropTech frontend demo for PG & hostel booking and management.

## Stack

React · Vite · Tailwind CSS · React Router · Recharts · Framer Motion · Lucide

## Run

```bash
npm install
npm run dev
```

## Portals

Use the top demo switcher:

- **Student** — marketplace, search, booking, account
- **Owner** — properties, bed inventory, rent, reviews
- **Admin** — approvals, analytics, operations console

Mock data only. Interactions persist in localStorage.
